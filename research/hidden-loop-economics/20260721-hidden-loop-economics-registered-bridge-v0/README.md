# Frozen Hidden-Loop Economics and Registered-Loop Bridge Quick Screen V0

Retrospective, research-only quick feasibility screen over the predecessor's exact frozen
opening population and four frozen hidden-loop families. It opens bounded historical economic
diagnostics and tests whether hidden-loop activity precedes or predicts registered semantic-loop
completion. It is not prospective validation, achieved P&L, a deployable model, or permission
to trade.

Run from the repository root:

```bash
.venv/bin/python research/hidden-loop-economics/20260721-hidden-loop-economics-registered-bridge-v0/run_screen_v0.py
.venv/bin/python research/hidden-loop-economics/20260721-hidden-loop-economics-registered-bridge-v0/audit_screen_v0.py
```

The binding contract was frozen before economic or registered-bridge results were calculated.
