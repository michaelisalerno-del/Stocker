# Emotion × Regime-Mix Coarse Loop-Family Funnel V0

This is a bounded retrospective, observable-only, structural-only feasibility screen. It asks
whether the frozen behavioural dimensions improve prediction of the broad first-loop family
within the next six completed five-minute bars, and whether the frozen soft V2 regime mixture
filters those behavioural effects.

The run uses the audited 20-stock cohort, only the 10:00 and 10:30 America/New_York checkpoints,
2024 development, and 2025-01-01 through 2025-08-22 assessment. The broad target is frozen from
2024 using the preregistered registered-subtype pooling rule and mandatory three-class fallback.
Tied registered completions and unavailable sources are excluded without lexical tie-breaking.

This experiment does not rerun either blocked exact-loop or active-prefix design. It opens no
returns, direction, P&L, entries, exits, stops, targets, trading rules, broker functionality, or
deployment surface. It is not prospective validation, economic-edge evidence, a strategy, or a
deployable system.

Run from the repository root with the research environment:

```bash
python research/loop-funnel/20260721-emotion-regime-coarse-loop-family-v0/run_screen_v0.py
```

The primary artifacts are written beneath `artifacts/primary/`; `reports/report.md` mirrors the
final report. The runner performs one bounded model pass, 50 fixed-prediction session bootstraps,
10 within-slate behavioural null draws, a fast three-model determinism refit, and a lightweight
independent audit.
