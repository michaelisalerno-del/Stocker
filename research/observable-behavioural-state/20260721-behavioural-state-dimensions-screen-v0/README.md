# Observable Behavioural-State Dimensions Screen V0

This bounded retrospective experiment asks whether fixed continuous dimensions of
observable opening behaviour add large-remaining-move or conditional-direction
prediction beyond the frozen Opening Regime-Path V0 observable M1 models.

The behavioural vocabulary is metaphorical: arousal, conviction, frustration,
tension, pressure, exhaustion, and independence are deterministic transforms of
completed five-minute price and historical activity-proxy rows. They are not
literal emotions, clusters, regimes, states, patterns, or trading rules.

The experiment is research-only and observable-only. It is not prospective
validation, achieved P&L, a strategy, or executable-edge evidence. Orders,
brokers, accounts, positions, sizing, deployment, and production runtime are not
used or modified.

Eligibility starts from the exact predecessor panel, then applies the fixed
complete-causal-history and 15-stock parent-slate requirements. Any resulting
row or slate exclusion is recorded; thresholds and frozen predecessor outcomes
are never recomputed on the reduced panel.

From the repository root, run the primary screen, exact rerun, and independent
audit with:

```bash
uv run python research/observable-behavioural-state/20260721-behavioural-state-dimensions-screen-v0/run_screen_v0.py
```

Primary artifacts are written to `artifacts/primary`, the deterministic second
run to `artifacts/exact_rerun`, and the narrative result to `reports/report.md`.
