## Pre-edit qualification decision

- Required broad point-in-time universe: **not available**. The safe raw five-minute
  population has 43 symbols, below the 50-stock valid-slate minimum, and the available
  generated universe is a current snapshot.
- Required point-in-time sector membership: **not available**. No effective-dated sector
  membership dataset was found. Current EODHD/IBKR classifications are not substitutes.
- Five-minute data: present, but the safe population is too small and processed files are
  protected because they contain post-cutoff rows.
- Bar label convention: ingestion stores EODHD timestamps directly and fixtures align the
  first timestamp with the session open, suggesting bar-start labels. No audited primary
  source proving the convention was found, so it remains unresolved for a scientific run.
- Adjustment/corporate actions: raw close is not silently adjusted; sampled NVDA audit
  metadata contains a split-like warning and no adjusted close. Corporate-action handling
  is therefore unresolved for this experiment.
- Provider volume is treated only as provider-reported activity proxy data, never order
  flow, quote flow, exchange-wide volume, or executable liquidity.
