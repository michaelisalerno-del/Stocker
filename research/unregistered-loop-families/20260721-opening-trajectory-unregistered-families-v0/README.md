# Opening Behavioural Trajectory → Unregistered Loop Families Quick Screen V0

Retrospective, observable-only structural feasibility screen using the frozen opening population
from Behavioural-Trajectory Funnel V0.1. It tests unregistered-event occurrence and a
development-frozen taxonomy of causal unregistered paths. It does not open economic or
directional outcomes, define trading rules, or enable execution.

Run from the repository root:

```bash
.venv/bin/python research/unregistered-loop-families/20260721-opening-trajectory-unregistered-families-v0/run_screen_v0.py
.venv/bin/python research/unregistered-loop-families/20260721-opening-trajectory-unregistered-families-v0/audit_screen_v0.py
```

The canonicalisation contract in `contract.json` was frozen before assessment hidden-family
support was calculated.
